# Aqua-Plastic-Cleaner# AI Aquatic Plastic Cleaning System 🛥️🌊

This project simulates an AI-based aquatic plastic cleaning system using Python and OpenCV.

## Features
- Plastic detection and collection simulation
- Cleaning boat movement on water surface
- Safe detection of aquatic animals (Fish, Turtle, Jellyfish)
- Plastic weight calculation
- Final cleaning summary screen

## Technologies Used
- Python
- OpenCV
- NumPy
- Pillow
